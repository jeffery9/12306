# 🌌 12306 本地数据中心 42U 标准服务器机柜空间排布、用电载荷与物理布线 LLD 规划白皮书

本规范承载着 12306 本地数据中心内，**42U 标准高密度服务器机柜（Standard Server Cabinet）** 的物理层落地标准。

为了保障在高密度服务器并发计算状态下的电力均衡、结构配重、气流冷却以及网络 MLAG 冗余接入的刚性稳定性，本白皮书对单机柜的 **空间单元（RU）、用电分配、物理布线、以及冷热气流通道** 实施像素级物理对齐规约。

## 2. 机柜空间规划与配重安全限制 (Space & Weight Constraints)

为了防止机柜发生头重脚轻导致倾覆，以及为了保障维护安全，配重分布必须符合 **“下重上轻”** 刚性律令：
1.  **高配重高负载设备下沉**：4U 重型 PostgreSQL 物理服务器、SAN 存储阵列、UPS 备用蓄电池组，强制放置于机柜下半部（**1U - 20U 黄金重载区**）。
2.  **中轻型计算节点居中**：2U 高主频双路 AMD EPYC 计算节点、Redis 纯内存缓存主机，放置于机柜中部（**21U - 37U 计算区**）。
3.  **极轻型网络设备封顶**：1U 交换机、ODF 光纤配线架，放置于机柜顶部（**38U - 42U 接线网络区**），便于上走线（Overhead Cabling）桥架无接缝光纤对接。
4.  **防气流乱涌挡板**：凡是未被物理填充的空置 RU 槽位（如 9U-12U, 21U-22U, 27U），**必须强制物理安装 1U/2U 黑色阻燃盲板（Blank Panels）**。
    *   **理由**：防止冷通道中的冷空气穿过空置槽位直接漏向热通道，或热回风发生涡流倒灌。保证冷热气流 100% 被服务器内置风扇强制物理水平抽吸。

## 3. 电力载荷与 PDU 冗余平衡方案 (Power Distribution)

单机柜最大设计电力载荷上限为 **$8 \text{ kW}$**。为了保障物理数据库或服务器电源（PSU）突发烧毁时核心业务不停机，实施 **双路互备电力平衡设计**：

```text
========================================================================================================
                                     DUAL-FEED PDU ELECTRICAL HARNESS
========================================================================================================

    [ Utility Substation / ATS ]                   [ Generator Backed / UPS ]
                 │                                             │
                 ▼ (Feeder A - Active)                         ▼ (Feeder B - Standby)
     ┌────────────────────────┐                    ┌────────────────────────┐
     │  PDU Strip A (Left)    │                    │  PDU Strip B (Right)   │
     │  (32A AC Input, Blue)  │                    │  (32A AC Input, Red)   │
     └───────────┬────────────┘                    └───────────┬────────────┘
                 │ (C13/C14 Jumpers)                           │ (C13/C14 Jumpers)
                 ▼                                             ▼
         ┌───────────────┐                             ┌───────────────┐
         │ Power Supply 1│                             │ Power Supply 2│ (Redundant Feed)
         │  (PSU 1 - A)  │                             │  (PSU 2 - B)  │
         └───────┬───────┘                             └───────┬───────┘
                 │                                             │
                 └──────────────────────►◄─────────────────────┘
                                         │
                                         ▼
                            [ 2U/4U Bare-Metal Node Server ]
========================================================================================================
```

### A. 物理 PDU 条规格
*   机柜后部左右侧，各垂直安装一根 **32A 12联 C13 + 4联 C19 智能监控 PDU 铜排**。
    *   **PDU-A（左侧，蓝色标识）**：连接机房市电主电源。
    *   **PDU-B（右侧，红色标识）**：连接发电机保护/在线式双变换 UPS 备用电力。
*   **计算公式（安全载荷预留）**：
    $$\text{PDU 安全工作容量} = 220 \text{ V} \times 32 \text{ A} \times 0.8 \text{ (降额系数)} = 5.632 \text{ kW}$$
    单路 PDU 在长期运行中，实际负荷绝不允许超过此阈值。两路 PDU 的最大用电载荷总额控制在 8 kW 以内，确保单路 PDU 突发断电时，另一路能在 **零微秒延迟内承载全部设备 100% 负荷工作**，而不会触发过载跳闸（Overload Trip）。

### B. 交叉接线硬核律令
*   所有安装的服务器（无论是 2U 计算还是 4U 数据库）必须选配**双冗余电源（Dual-PSU）**。
*   **物理连接**：服务器的左侧 PSU-1 电源线必须接入左侧的 PDU-A，右侧的 PSU-2 电源线必须接入右侧的 PDU-B。**严禁为了贪图理线方便，将一台服务器的双电源全部插入同一侧的 PDU**。

## 4. 物理布线与接口 MLAG 绑定规约 (Cabling & Networking)

```text
========================================================================================================
                                 RACK CABLING & PORT MLAG INTERFACE MAP
========================================================================================================

                                  ┌───────────────────────┐
                                  │      Spine Layer      │ (AS 65000 / Core Clos)
                                  └─────▲───────────▲─────┘
                                        │ (100G QSFP28)   │ (100G QSFP28)
                    ┌───────────────────┘                 └───────────────────┐
                    ▼ (MLAG Peer Link)                                        ▼
         ┌─────────────────────┐                                   ┌─────────────────────┐
         │  Leaf Switch 1 (L1) │◄─────────────────────────────────►│  Leaf Switch 2 (L2) │
         └─────┬───────────┬───┘          (2x 100G Direct)         └─────┬───────────┬───┘
               │ (LACP-Active)                                           │ (LACP-Active)
               │ (25G SFP28 DAC)                                         │ (25G SFP28 DAC)
               └───────────────────┐                             ┌───────┘
                                   ▼                             ▼
                            ┌────────────────────────────────────────────┐
                            │  Dual-Port 25G Server Network Card (LACP)  │
                            └────────────────────────────────────────────┘
========================================================================================================
```

### A. MLAG 交换机级网络冗余
*   顶部 **RU 40（Leaf-1）** 与 **RU 39（Leaf-2）** 互为 MLAG 邻居。
*   两台 Leaf 交换机之间通过 2 个 100G QSFP28 物理端口建立 **Peer-Link** 互联，将控制平面逻辑虚拟化为单一交换机，但保留物理数据面隔离。

### B. 服务器网络 LACP 汇聚
*   服务器内置双口 25G SFP28 光学/DAC 网卡。
*   **物理布线**：口 1（`NIC-1`）使用 25G SFP28 铜质直连电缆（DAC，最大长度 2m，超低传输延迟，节约昂贵的光模块）连接到 `Leaf-1` 的对应接口；口 2（`NIC-2`）连接到 `Leaf-2` 的对称接口。
*   **逻辑汇聚**：服务器操作系统内对该双 25G 网卡组建 **LACP 链路聚合（IEEE 802.3ad，模式 4）**。这使得该服务器在拥有 50G 高能合并带宽的同时，在 `Leaf-1` 整体因硬件损毁发生断电离线时，**网络数据流可以在 sub-50ms 内无感漂移到 `Leaf-2` 备份通路上**，微服务 TCP 连接绝不断开！

### C. OOB 带外管理独立网
*   **RU 38（OOB 交换机）**：
    所有服务器的 **IPMI / iLO / iDRAC 独立物理管理口**，以及两台主 Leaf 的 Console / Management 口，必须全部统一用六类双绞线（CAT6 RJ45）接入 RU 38 交换机，彻底实现带内带外物理分离。

## 总结 (Summary)

通过推行本套 **42U 高密机柜空间与物理部署规范**：
1.  我们不仅依靠 **“下重上轻”** 确保了物理数据中心的物理重心下沉、设备搬运装配安全性；
2.  依靠 **“双路 A+B 电力交叉接线”** 和 **单 PDU 5.6 kW 安全红线** 彻底豁免了电源、配电级单点崩溃（SPOF）灾难；
3.  更结合顶部的 **100G MLAG 链路聚合** 与 **LACP 50G 双 DAC 极速卡位**，为 12306 多后端高吞吐数据流通提供了物理层的低延迟、高抗震、超强容灾网络硬件地盘，确保在春运抢票洪峰中物理设施坚如磐石！
