## 1. 财务模型假设 (Financial Hypotheses)

为了进行精确的成本推导，我们采用以下财务基准假设：
*   **计算模式**：**混合云模式（Hybrid Cloud）**。强事务的数据库（MySQL）、高性能缓存（Redis）及消息队列（Kafka）部署于自建私有机房物理服务器，以确保最高物理安全性与低延迟。无状态的 Web 网关服务（K8s Web Pods）及 CDN 边缘下沉节点，部署于公有云弹性算力池，以充分利用弹性扩缩容（HPA/KEDA）的经济优势。

*   **物理机房选型**：Tier 3+ 标准，配备 2N 冗余电源，高功耗机柜（8kW/Rack）托收。

## 3. OPEX 运营支出（托管、带宽与网络）

运营成本（OPEX）为系统日常运转所需支付的数据中心、网络带宽以及专线费用。

### A. 机柜租用、电源与冷却费 (Rack & Power Costs)
*   总计物理设备：`512 + 256 + 16 + 156 + 12 = 952台`。
*   采用高功耗机柜（8kW/Rack），按每个机柜容纳 20 台 1U/2U 机器（需考虑配电和发热限制）估算：
    *   总需机柜数量：`952 / 20 ≈ 48 个机柜`。
    *   一线城市 Tier 3+ 优质机房托管费（含 8kW 电力基准）：约 **¥8,000/个机柜/月**。

```text
  [ 物理机房托管总费用 ] = 48 个机柜 * ¥8,000/月 * 12 个月 ≈ ¥4,608,000/年
```

### B. CDN 与网络带宽费用 (CDN & Bandwidth OPEX)
得益于我们的 **“L1边缘拦截策略”**，90% 的查询流量已被 CDN 和边缘缓存阻断。

#### ① CDN 出网流量费（边缘出网）
*   49,500,000 QPS 读流量。平均 QPS 经过削峰与时间拉平后，平均在线流量约 **8 Gbps**（万兆级出网）。
*   公有云/大客户 CDN 带宽按保底按月带宽计费：单价为 **¥12,000/Gbps/月**。
```text
  [ CDN 边缘宽带费用 ] = 8 Gbps * ¥12,000 * 12 个月 = ¥1,152,000/年
```

#### ② 中央机房 BGP 独享宽带（穿透入源 10% 流量）
*   中央机房回源及写通道，平均流量占用约 **0.8 Gbps**。
*   机房独享三线 BGP 专线带宽单价：约 **¥45,000/Gbps/月**。
```text
  [ 中央 BGP 专线费用 ] = 0.8 Gbps * ¥45,000 * 12 个月 = ¥432,000/年
```

#### ③ “两地三中心”多活机房互联裸光纤（Dark Fiber）
*   北京、上海、西安三个物理基地采用环状专用万兆冗余暗光纤进行高速互联（保障数据库两阶段提交与 EDA 消息物理跨机房极速同步）。
*   双芯万兆光纤跨省专线租赁费：约 **¥150,000/条环线/月**。共 3 条专用环线。
```text
  [ 跨省多活互联光链费用 ] = 3 条环线 * ¥150,000 * 12 个月 = ¥5,400,000/年
```

## 5. 云原生弹性扩缩容降本增效 (Autoscaling ROI Analysis)

通过引入 **K8s HPA + KEDA 弹性伸缩**，无状态 API 容器（5000+ Pods）在每日夜间 23:00 至 次日 06:00 购票低谷期，允许实例自动归零（缩容至 5 个基础 Pod 保底）。
*   **传统静态配置**：必须常年租用 5000 个 Pod 的公有云虚拟算力。
    *   5000 Pods * ¥300/Pod/月 * 12 个月 = **¥18,000,000/年**。
*   **弹性伸缩自愈配置**：每日仅在 08:00~20:00 高峰期（12小时）跑满 5000 Pod，其余 12 小时缩容至 5 个 Pod，折合平均每日仅消耗相当于 2500 个 Pod 的算力：
    *   2500 Pods * ¥300/Pod/月 * 12 个月 = **¥9,000,000/年**。

```text
  [ K8s / KEDA 弹性伸缩年度直接节省开销 ] ──► ¥18,000,000 - ¥9,000,000 = ¥9,000,000/年 (降本达 50%！)
```
